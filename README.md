# Employee Service

This project is part of an employee and department microservices application built using Spring Boot

## Features
- Add new employees
- Get employee details
- Update employee details
- Delete employee records
- Get department details for an employee

## Database
employee_microservices_db

## Run the project
1. Import the project into Eclipse
2. Configure MySQL in - application.properties
3. Run the Spring Boot application
